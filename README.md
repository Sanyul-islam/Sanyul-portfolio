# Sanyul Islam — Portfolio

A modern, responsive personal portfolio website built to showcase my skills, projects, experience, and contact information as a Full Stack Web Developer.

## 🌐 Live Website

[Visit the live portfolio](https://sanyulislam.vercel.app/)

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Sticky transparent/glass-style navigation bar
- Active navigation link based on the current scroll section
- Hero section with personal introduction and call-to-action
- Technology stack carousel with continuous autoplay animation
- About section
- Services and skills section
- Projects showcase with project previews and links
- Contact section
- Footer with social links
- Smooth section navigation
- Modern dark theme
- Blue-to-sky gradient typography
- Neon green accent color
- Responsive mobile navigation menu
- Optimized images using Next.js Image
- Deployed on Vercel

## 🚀 Getting Started

### 1. Clone the repository

`git clone YOUR_GITHUB_REPOSITORY_URL`

### 2. Navigate to the project directory

`cd YOUR_PROJECT_FOLDER`

### 3. Install dependencies

`npm install`

### 4. Start the development server

`npm run dev`

Open [http://localhost:3000](http://localhost:3000) in your browser.
